📝 Custom Formatting

Hidden Feature

📚 Auto Chapters

Available English Only

Automatically summarize your audio into chapters. The Auto Chapters model makes it easy for users to navigate and find specific information.

What Each Chapter Contains

  • Summary: One-paragraph summary of the content
  • Gist: One-line summary in a few words
  • Headline: Single sentence summary
  • Timestamps: Start and end times for navigation

📊 Example Output

Chapter 1: "Smoke from wildfires triggering alerts"

Timestamps: 0:00 - 0:28

Summary: Smoke from hundreds of wildfires in Canada is triggering air quality alerts throughout the US. Skylines from Maine to Maryland to Minnesota are gray and smoggy...

Gist: Wildfire smoke affects US air quality

✅ Best Use Cases

  • Podcast navigation and show notes
  • Long meeting recordings with multiple topics
  • Educational content with distinct sections
  • Customer calls with multiple issues discussed
  • Conference talks and presentations

🏷️ Topic Detection

Available Multiple Languages

Identify different topics in the transcript using the IAB Content Taxonomy - a standardized language for content description consisting of 698 comprehensive topics.

How It Works

The model analyzes your transcript and categorizes it into predefined topics from the IAB (Interactive Advertising Bureau) taxonomy. Topics are hierarchical with supertopic/subtopic relationships.

📊 Example Topics

  • NewsAndPolitics > Weather - 100% relevance
  • Home&Garden > IndoorEnvironmentalQuality - 90% relevance
  • Science > Environment - 16% relevance
  • MedicalHealth > DiseasesAndConditions > LungAndRespiratoryHealth - 11% relevance

📄 Summarization

Available English Only

Generate a single summary of your entire audio file. Control the style and format of the summary using Summary models and Summary types.

Summary Types

Type Description Best For
bullets (default) Bulleted summary with most important points Quick reviews, action items
bullets_verbose Longer bullet point list Comprehensive summaries, detailed notes
gist Few words summarizing entire transcript Tags, categories, quick labels
headline Single sentence summary Email subjects, titles, quick overviews
paragraph Single paragraph summary Executive summaries, reports

Summary Models

Model When to Use Supported Types
informative (default) Single speaker (presentations, lectures) bullets, bullets_verbose, headline, paragraph
conversational 2-person conversations (calls, interviews) bullets, bullets_verbose, headline, paragraph
catchy Creating media titles headline, gist

  • With climate change, we are seeing more wildfires

When to Use Pre-recorded vs. Streaming?

Speaker diarization needed ✅ 2.9% error rate ⚠️ Coming soon

Hybrid Approach (Recommended)

🎯 Best of Both Worlds

  1. During the call: Use streaming for live captions and real-time notes
  2. After the call: Use pre-recorded for final transcript with speaker labels, summary, and insights

This gives users immediate value during meetings while providing comprehensive documentation afterward.

How to Improve Accuracy

✅ Keyterms Prompting

Improve recognition accuracy by up to 21% by providing domain-specific vocabulary:

  • Participant names: "Dylan Fox", "Sarah Chen", "Michael Rodriguez"
  • Company terms: "AssemblyAI", "Universal-Streaming", "Speech Understanding"
  • Technical terms: "API endpoint", "WebSocket", "latency metrics"
  • Best practices: Max 100 terms, under 50 characters each

Handling Multichannel Audio

Many meeting platforms (Zoom, Teams, Google Meet) can record each participant on separate audio channels for dramatically improved speaker identification:

  • Perfect speaker separation - No diarization errors
  • No confusion or overlap - Clean single-speaker audio
  • Faster processing - Diarization not needed
  • Higher accuracy - Model processes clean audio
